# Contributing

## Getting Started

1. Fork the repo
2. Build the project:

   ```bash
   make
   ```
3. Create a new branch for your change:

   ```bash
   git checkout -b feature/your-feature
   ```

---



## Guidelines
- Update `docs/` if your change affects behavior or the archive format
- Format your code before committing:

  ```bash
  clang-format -i src/*.c includes/*.h
  ```


---


## Reporting Bugs

Open an issue with and explain what you expected, and what happened.
